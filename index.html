Your Reelin VPN key

This page makes the key your computer needs to join the Reelin VPN. It all happens inside your browser: nothing you type and nothing it makes is sent anywhere.

This browser cannot make the key. Open this page in a current Chrome, Edge, Firefox or Safari.

Before you start: ask Vincent on Teams for a VPN address. It looks like 10.8.0.23.

  1. Type your VPN address

    That is not an address Vincent gives out. Type the one he sent you, such as 10.8.0.23: 10.8.0. and a number from 2 to 254.

  2. Make your key

    This is your public key, made for the address . It is not secret: it goes into your request.

    Wrong address? Reload this page and start again.

  3. Save your key file

    The file holds the private half of your key, and it is the only copy: this page keeps none. Save it before you leave this page.

    Saving again after a reload? First delete the earlier reelin.conf from your Downloads folder.

    Your browser saves it as reelin.conf, usually in your Downloads folder. If an earlier one is still there, it may name the new one reelin (1).conf.

    Cannot find it? Reload this page and start again. That makes a new key, with a new public key.

The file is your key. Never send it to anyone, and never paste what is in it anywhere, not even to Vincent. Anyone who has it can join the VPN as you.

Then: send your public key

Open the request form, choose New VPN device, type the same VPN address you typed in step 1 into VPN address, and paste the public key.

No GitHub account? Send the public key and your VPN address to Vincent on Teams instead.

Never send the file. You are told when your request is applied: by an email from GitHub, or by Vincent.

Windows

  1. Install WireGuard from wireguard.com/install.
  2. In WireGuard, click Import tunnel(s) from file and choose the file you saved.
  3. In your Downloads folder, select the file you saved and press Shift+Delete, so that it does not stay in the Recycle Bin. WireGuard keeps its own copy.
  4. Once you are told your request is applied, click Activate.

Ubuntu

In a Terminal:

sudo apt install -y wireguard

On Ubuntu 22.04, also:

sudo apt install -y resolvconf

Then put the file you saved in place and delete the downloaded copy:

sudo install -m 600 ~/Downloads/reelin.conf /etc/wireguard/wg0.conf
rm ~/Downloads/reelin.conf

If the file you saved has another name, such as reelin (1).conf, use that name in both lines, in quotes: ~/Downloads/"reelin (1).conf".

Once you are told your request is applied:

sudo systemctl enable --now wg-quick@wg0

This connects now and at every start of the computer.

This page holds nothing secret: only the VPN server's public key, its address and the VPN's address ranges. Its code is at github.com/reelin-access/vpn-key.
